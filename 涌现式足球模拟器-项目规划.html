PROJECT VISION · 涌现式 AI 足球模拟 v1.0

涌现式足球模拟器 · 项目规划

终极目标:把人类真实踢球的感觉量化为数据,用数据驱动的方式模拟人类现实足球的场景。 真实比赛里球员的每一个选择——传/带/射/过、站哪里、何时逼抢、被侵犯后是否上头——都拆解为可计算的数学结构,让智能体"涌现"出真实、每场不同的战术行为。

引擎: Godot 4 / 当前 HTML+JS 沙盒 路线: 力场叠加 + 阈值触发器 版本: v2.0 可玩(3v3) 规模: 3v3 起步 → 11v11

1项目定位与终极目标

终极目标
把"人类真实踢球的感觉"量化成属性、效用权重、空间价值、身体对抗与第三维空间的数学结构,模拟现实足球场景
不是
FIFA/实况的操控型,也不是 FM 的"数值概率掷骰子"
核心卖点
涌现式智能体:调整战术(权重/阵型)后,球员行为"肉眼可见"地变化(因果感)
技术路线
控制论 / 力场叠加(感知 → 决策 → 驱动),混合少量阈值触发器;非 RL 端到端、非 LLM 决策

量产化思路:感觉 → 数据

人类踢球的感觉量化形式
这个队友能接住吗 / 该传他还是自己带属性(决策属性) + 效用权重(取舍标准)
这块空当对我们有利,我该站过去空间价值评分(开放度/通道/推进/宽度/车道)
抢他一下,撞一下,踉跄一下身体对抗掷骰 + 踉跄状态(动量/失衡)
这球太高了,跳起来顶/等它落地第三维空间(高度 alt / 重力 / 头球窗口)
被连续侵犯,火气上来了情绪层(愤怒值 → 报复欲力场,规划中)

2核心架构(感知 → 决策 → 驱动)

感知层 · 传感器
视野误差(离球越远越不准,按"视野"属性)、局部观测、队友传球后的"接应"感知。禁止上帝视角——球员信息不对称才真实。
决策层 · 主控
效用式决策(控球者:射门/传球·地面高空/带球/过人,取最大)+ 角色式站位(无球者:支援/逼抢/回防/抢球/补位)+ 蓄力 + 阈值触发器 + 反击爆发。
站位评分:分数 = 开放度 + 传球通道 + 推进价值 + 宽度 + 车道(选"对比赛最有利"的点)
驱动层 · 身体
目标力 + 斥力(对手为主,队友极弱)+ 惯性 + 摩擦;踉跄状态(减速 45%、无法停球/拦截/抢断)。 身体限制迫使决策层"提前预判",自然产生跑位。

关键纪律:决策层写成纯逻辑、与引擎无关(输入感知数据 → 输出目标点/力向量)。引擎只是"身体","大脑"独立,便于换引擎/测试。

5关键设计决策(ADR 记录)

ADR-1

纯涌现不够。力场为主 + 少量阈值触发器/规则混合,这是实际可行的平衡点。

ADR-2

涌现 ≠ 没有神阵。只是提高找漏洞门槛、缩短生命周期;连续系统同样可被反向工程。

ADR-3

快模型是慢模型的压缩版。若做自动战斗,必须用慢模型蒸馏校准结果分布,否则玩家不信任。

ADR-4

调参纪律。一次只动一个参数 + 可视化 + 记录行为变化(和调 PID 同一套方法论)。

ADR-5

观测必须带误差/局部视野。这是"真正对战感"的来源,也是防止 AI 作弊的关键。

ADR-6

调试是常态。涌现系统会集体抽风(扎堆、转圈),压制而非消灭。

ADR-7

身体限制是真实感的根基。踉跄/动量/蓄力都是"身体做不到"带来的自然决策。

ADR-8

防守需要"节奏停顿"。拦截/抢断后必须有踉跄期,否则乒乓式反复拦截。

6难点与风险

调参地狱:多智能体耦合,权重微调全局变样 → 靠调参面板 + 遥测数据。

混沌崩溃:涌现行为偶尔失控 → 阈值触发器压制。

因果感:玩家调整战术后必须感知到效果 → 战术预设 + 建议键给出明确参照。

调试困难:涌现系统的 bug 是蝴蝶效应 → 可视化 + 最小复现 + 日志导出。

11设计中:感知层 + 上下文记忆 + 基本规则集

讨论中 · 尚未实现

重构方向:让智能体从"反应式"进化为"预测式"。核心结构:感知快照(只依据"已知信息"决策)+ 上下文记忆(环形缓冲 + 一阶外推)+ 统一威胁/空间价值。

11.1 感知层规格(先只做视野)

项规格
视野锥朝向 = 移动方向(静止时朝对方球门);张角 120°;半径 = 150 + 80×vision
球始终可见(注意力焦点),但带距离相关高斯误差
遮挡"我→目标"线段与任何球员圆相交 → 不可见;不可见期间记忆停更、1s 后清空
感知误差高斯噪声,σ ∝ 距离 × (1 − vision),上限 45px(替代现在的均匀 ±80px)
采样10Hz,与决策同频;两次采样间用缓存
声音(下期)事件队列:队友喊话("我空了"/压迫)、球触地声——只给方向不给精确位置

11.2 上下文记忆(三层各存各的,记忆反作用于决策)

记忆不只存感知——感知/决策/驱动三层的状态都入记忆,且都能反过来影响决策。

感知记忆(核心,已设计)
项规格
存储每球员自带环形缓冲 30 条(@10Hz ≈ 3s);每条 {t, x, y, vx, vy}(速度由最近两次观测差分估计)
预测一阶外推:未来位置 = 最后观测 + 速度 × T,T = 0.35s(人类反应 + 出球时间)
不确定性置信度 conf = exp(−记忆陈旧度/0.5);预测位置加高斯噪声,σ = 24 + 陈旧度×70——越久远越"模糊的一大片"
丢失规则对象被遮挡 >1s → 记忆清空,预测返回 null(不能透视,看不见的人就是"消失了")
反作用防守通道封堵、传球通道评估、逼抢目标、支援开放度,全部使用对手的预测位置(R5)

队友记忆 = 默契度(规划):队友被遮挡时不清空——用"战术期望"(阵型锚点 + 球位偏移)填补他的位置。传球给看不见的队友是默契不是赌(现实里球员坚信队友会跑到那里)。对手记忆仍按遮挡 1s 清空(不能透视)。

决策记忆(设计定稿)
项规格用途
我的决策滞回role / roleAt(0.4s 内不换角色)已实现,防站位抖动
我的动作记录lastAction / lastActionAt支持"刚被过 → 立刻回追"等连续性行为
对手习惯每对手最近 3 次变向方向统计 trickDir[±1]防守站位时:对手习惯向右 → 封堵该侧重心(通道封堵偏置)
传球目标冷却不连续两次传同一队友避免"一根筋传一人"被断
驱动记忆(身体状态,喂给情绪层)
项规格用途
身体失衡stagger / windup(已有字段)驱动层状态记忆,已实现
疲劳(规划)连续冲刺时间累计 → 速度衰减 + 抢断失误率上升让"跑不死"不存在
被侵犯记录最近 30s 内"被谁侵犯"次数(情绪记忆)愤怒值累积来源之一:同一个人连犯三次 → 上头

三层反作用闭环:感知记忆 → 预测(R5);决策记忆 → 滞回 + 习惯对抗;驱动记忆 → 情绪层(愤怒值)→ 冲突。核心三件套(感知/记忆/规则)至此定稿。

11.3 感知快照(决策层只依据"已知信息")

每次决策前构建 view 快照:球(实测 + 误差)| 每个其他球员:视野内 → 实测带误差并写入记忆;视野外 → 从记忆外推预测(带置信度)。所有决策函数从快照读位置,不再直接读全局坐标。物理碰撞/斥力仍用真实位置(身体层永远是真实的)。

11.4 决策层基本规则集 R1~R6(讨论定稿)

#规则数学形式
R1空间价值 = 期望值V(x,y) = P(成功)×Gain − (1−P)×Loss(高风险高回报空间由期望值自动权衡)
R2进攻 = 创造最大威胁支援/跑位 = argmax(空间价值 + 空间创造加分:站两防守者之间 / 防线身后)
R3防守 = 压制威胁站位 = 覆盖"对手可达且 Gain 高"的点(队友协调惩罚),最近者仍逼抢持球者
R4控球者效用5 候选 = 收益×成功率×风格权重(量纲归一化到 0~1)
R5预测优先所有"对手位置"用记忆外推值,置信度衰减
R6破局计时器控球方连续 3s 无 P×Gain > 阈值机会 → 冒险系数爬升(远射/单打/往身后起高球)

11.5 威胁度公式(用作 Gain/Loss 的后果评估,不是站位驱动力)

Threat(x,y) = 推进价值 exp(−距球门/320) × 空间价值 min(距防守者距离)/150 × 通道价值 × 球员能力(0.5+0.5×射门)(0.5+0.5×速度) × 动量(0.5+0.5×dot(速度,朝向球门))。
站位用空间价值(过程指标),威胁度只用于评估"打穿的收益"与"被反击的损失"——防止阵地战倒脚。

11.6 R4 控球者效用重构(定稿)

U(动作) = 收益(0~1) × 成功率估计(0~1) × 风格权重 × 风险系数
所有效用归一化到 0~1(解决原版各动作量纲不一、权重不可预测的问题);噪声改为比例噪声(±10%)。
动作成功率估计(草案)收益
空门射门≈ 0.90距门越近越高
干扰下射门≈ 0.30同上 ×0.6
传空位队友≈ 0.85推进量(预测落点)
被盯防传球≈ 0.35推进量
高空球(通道被挡时)≈ 0.55推进量(越远越划算)
直塞身后≈ 0.25(高风险高回报)推进量 ×1.8
过人盘带 / (盘带 + 防守)(已有雏形)摆脱后的空间
带球1 − 被逼抢程度推进 + 保持球权

风险系数 = f(比分, 剩余时间, 破局计时器):落后/末段 → 愿意赌低成功率高收益的动作(直塞/远射);领先 → 偏向高成功率动作。
数值策略:成功率表先用静态查表,管线跑 3 档对比(如干扰下射门 0.2/0.3/0.4 各 10 场),挑行为最像真实足球的档位;验证后再升级为动态估计(由感知数据算连续函数)。

11.7 解围机制(迫于无奈,规划)

持球者被层层包围(贴身 2 人以上)且无传球通道、无推进空间时,破局计时器进入绝望档:
① 大力解围:朝前场高空大脚(成功率低,但避免无限护球被抢)→ 标签"解围!"
② 近门时:强行射门(哪怕被挡)
触发优先级高于正常效用(生理性动作,不经过理性权衡),是 R6 破局计时器的极端档。

改参数/改规则 → 重跑;完成后自动删除旧轮 data/runs 目录,只留最新
