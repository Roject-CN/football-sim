v1.0 · 战术系统最新2026-08-12
目标:不同打法肉眼可区分——把"战术"从参数名变成按钮。
新增
  • 战术预设 ×5:均衡 / 传控 / 防守反击 / 长传反击 / 高位逼抢,一键切换(20 参数捆绑,滑条同步)
  • 4 个新参数:防线深度(0.15~0.6)、逼抢强度(0~2,≥1.3 两人夹抢)、支援距离(0.4~1.6)、高空球倾向(0~2)
  • 反击爆发:抢断/拦截/夺回球权瞬间,全队 2.5s 冲刺前插 + 直塞权重翻倍 + 推进价值 ×2.2(防反的灵魂)
  • 打法建议键:按比分 + 剩余时间给出战术建议并一键应用,附理由
验证(各预设模拟 90s)
预设比分射门地面传球高空球头球抢断拦截
传控2:1311213132710
防守反击7:413861818263

四种打法指纹差异显著:传控 = 地面球最多,防反 = 射门暴击,长传 = 空战,高位 = 抢断/拦截机器。
v0.9 · 精度修复2026-08-12
来源:用户导出比赛日志,逐条定位问题。
修复
  • 高空球贴脸被拦:高空球初始高度 40,出脚瞬间越过贴身逼抢者
  • 传球改传预测落点:目标 = 接球者位置 + 速度×飞行时间,传跑结合而非传静止点
  • 对抗天平:抢断基础概率 0.22→0.30、逼抢失败踉跄 0.5→0.35s,打破"扛住逼抢"无限护球
  • 日志分段导出:按"比赛开始"自动分段,每段带本场统计
验证:传球成功率 81~87%(修复前 ~65%),高空球贴脸被拦 0 次,比分回归均衡(2:2 / 2:0 / 2:5)。

v0.6 · 高空球与头球2026-08-12
来源:"传球加入 Y 轴吧,加上头球和高空球,要不然空间太小了"——第三维空间。
新增
  • 球场加高(420→500px),纵向空间 368→440px,网格/车道/锚点同步放大
  • 球高度属性 alt/altV:重力 + 空中低阻力,飞行更远
  • 传球分地面/高空:地面通道被挡时高空球效用骤升(越过拦截者头顶)
  • 头球:20~90 高度、40px 内争顶,攻方顶向球门、守方解围;0.35s 冷却
  • 渲染:球影随高度缩小 + 球体抬升
调试中修复的两个 bug
  • air 判定与高度积分循环死锁(球永远升不起来)→ `alt > 0 || altV > 0` 即视为空中
  • 头球悬停连顶(2500 次/场)→ 头球后球落到地面 + 冷却
验证:头球 14~20 次/场,比分 0:0 / 1:0 / 1:3。
v0.5 · 空间价值定位2026-08-12
来源:"队友刻意保持距离——站在这里不是因为我需要离队友远,而是因为这块空间有利于比赛"。
重构
  • 进攻支援:5×5 候选网格打分 = 开放度 + 传球通道 + 推进 + 宽度 + 车道,选"对比赛最有利"的点
  • 防守回防:站线 + 个人车道 + 封堵持球者传球通道
  • 队友斥力 140→55(46→32px):间距由"选了不同的好位置"涌现,而非被推开
  • 接应跑位(冲刺迎球)+ 角色滞回 0.4s + 传球通道评分
验证:拦截率从"满天飞"降到个位数,传球成功率显著上升。

v0.1 · 最小沙盒2026-08-12
目标:验证"力场叠加 → 涌现"是否可行。
实现
  • 1D 简化版(不引入 Y 轴):6 球员 + 球在一条跑道上
  • 效用式决策(控球者 5 候选)+ 无球角色(逼抢/回防/支援/抢球/补位)
  • 拦截/封堵由物理碰撞自然产生——无一句特判代码
  • 感知误差(视野属性)、决策噪声、属性随机化
结论:涌现式 AI 完全可行,拦截等行为是物理的天然产物。
