v2.9 · 动作涌现化(射门方式由局势决定)最新2026-08-12
原则回归:"不是特意增加动作,而是自然的逻辑——根据对方站位计算自己的射门/传球方式"。
实现
  • 移除离散挑射候选动作——挑射/低平/弧线不再是独立按钮,而是射门执行的连续方式选择:门将离门线出击且近 → 吊射过顶(带弧线);门将在位 → 低平/推射远角;空门 → 随机打角
  • gkCoverage 加入出击惩罚:门将离门线越远,覆盖越低(×[1−0.55×出击度])——评估/扑救/xG 三处同模型,出击空当被射门自然利用,不再需要"挑射专用判定"
  • 弧线球:挑射带横向 bend(空中持续偏转),路线多样
  • 传球同理:地面/高空由"通道是否被挡"这一局势自然选择(已有),不再增加特判
验证(3场均值):均衡 2:2/1:3/7:0,挑射 0~2 次/场(门将出击时才涌现),正常射门照常。管线报告见 data/runs/latest。
v2.7 ~ v2.8 · 动作细节与死球机制 + 上线部署上一版2026-08-12
目标:带球/射门/发球的动作细节真实化,并把项目部署到公网。
实现
  • 暴趟(v2.7):第一脚把球趟远再追(150~300px,按到达时间反推初速),空间开阔/反击/甩追兵时使用,趟大了会被断/出界
  • 贴脸射门瞬时出脚(v2.7.1):力量下限 300→140,门前 50px windup≈0.02s(1帧);蓄力标签时长随蓄力缩短
  • 死球机制(v2.8):边线球有发球人(走到边线内侧掷,球停在场外);球门球由门将/最近队员走到球处开球——不再"球瞬移到人脚下"、不再"拿球被背后逼抢"
  • 蓄力随感知(v2.8):压力↑ → 蓄力缩短 45~50% + 误差放大 2~2.5 倍(仓促出脚更糙);空间足 → 从容更准——失误是量化的
  • 回传门将(v2.8):压力越大越有价值的安全出口(压力小时几乎不选);门将开球力度适中(落点中前场,队友可控)
  • 解围增强(v2.8):己方禁区内被贴身直接大脚解围;被围困 2 人+耐心耗尽解围;解围高弧线飞远(3~6 次/场)
  • 日志统一:门将显示"红门/蓝门"而非编号
  • 门将读场(v2.8.1):出击前判断场上局势——队友已覆盖(比我更近/站住球-门线路)就留门线;被清走的球不追;只有对方持球或门前自由球且我更有把握才出击
  • 死球/发球保护(v2.8.2):边线球、球门球发球后有 0.8~1.2s 保护期(不会被立刻抢);门将持球始终不可抢;速度改为下拉菜单(慢速 0.25x/0.5x + 1x/2x/4x)
  • 传球与门将开球精度(v2.8.3):传球误差基数 60→45、压力系数 2→1.2(成功率 74%→86~91%);门将大脚根因修复——球速按"落点=目标"反推(原先固定 520 会飞过目标 260px 出界),目标安全区 90px 余量、中路优先
  • 消除乌龙球(v2.8.4):己方门前 100px 内持球直接解围(杜绝带球进门);回传(朝己方方向/给门将)误差减半、门将目标球速保底 380;门将没收半径 14→26px;回传效用己方半场方向 ×0.65
  • 门将扑救高空球(v2.8.5):扑救触发门槛 160→100(高空球/头球/飘球不再被无视);门将不参与头球争顶(用扑救/没收处理)
  • 射门选角(v2.8.6):修复 shoot≈1 时误差为零永远射正中央的 bug;瞄准点看门将站位打远角(空门随机打角),散布按射门属性;xG 用瞄准点评估;传球落点前领 +12px
  • 挑射/吊射(v2.8.7):门将离门线出击时,持球者吊过门将头顶入网(1v1 权重×1.2、成功率 0.6-0.78);扑救对高空球有够不着惩罚(×0.45);门将站门线则正常射门

v2.6 · 守门员系统历史2026-08-12
目标:门加大 + 禁区 + 门将智能体(同一套 感知→决策→驱动,不是特判脚本)。
实现
  • 几何:球门 100→150px,禁区(160×480),小禁区(60×200),门将金色渲染编号"门"
  • 门将四角色:选位(站"球→门中心"连线封角度)/ 出击(门前 230px 有把握先到)/ 扑救(预测进门点外推,与记忆层同款)/ 开大脚(找前场队友或纵深)
  • 覆盖模型三处共用:射门评估 gkFactor / 扑救判定 / xG 统计——同一个模型,评估与结果一致
  • 射门判断升级:成功率 × (1−门将覆盖);门将离位 = 空门(覆盖骤降);角度 = 球门两柱张角;门将贴身 = 1v1 推射加成
  • 阈值触发收紧:需"门将不在位"才无条件起脚
  • 配置:红/蓝门将勾选框(默认开);传控/支援不回传门将;慢球门将优先(禁区内可用手)
调试中发现并修复的两个 bug
  • 扑救逐帧掷骰→ 球在覆盖区停留 0.2s=12 帧 ≈ 必扑(0:0 泛滥)→ 改为"每次进入覆盖区只掷一次骰"
  • 头球速度 170~330 低于扑救触发阈值 240 → 门将无视头球(长传反击 0:13 炮轰)→ 阈值降至 160
验证(3场均值):均衡进球 6、扑救 2.7、xG 2:1.5;传控 2.3 球(最少,控球锁死);防反/长传 8-10 球(快攻/空战);均衡总比分 5:5。扑出弹回 → 门前混战补射,机制自然运转。
v2.1 · 从"小孩踢球"到"校队"(二过一/节奏/假动作/协防)上一版2026-08-12
来源:外部评价"有小孩踢球的水准,懂基础站位"——针对四个短板逐项补课。
实现
  • 二过一(撞墙配合):传完球进入 1.5s 前插状态(标签"前插"),配合预测落点传球,队友可直塞回来——传跑一体化
  • 节奏控制:teamRisk 按 比分+时间 调整冒险系数——领先且末段收着踢,落后敢赌、末段更凶
  • 假动作:被压迫时 12% 概率虚晃一枪(横向变向),1s 内过人成功率 +0.12(对手重心被骗)
  • 防守协同:队友上抢时,防线收紧(×0.92)并整体向球侧收拢,防止"一过全过"
  • 逼抢追拦截点:逼抢/抢球目标 = 球预测位置(球位置 + 速度×0.3),不再追着球屁股跑

v2.0 · 智能重构(感知/记忆/效用规则)上一版2026-08-12
目标:把设计定稿的"感知层 + 上下文记忆 + 基本规则集"全部落地,让 AI 从"反应式"变"预测式"。
实现
  • 感知层:视野锥(120°/380px)+ 对手遮挡(队友不挡视线)+ 高斯误差 σ∝距离 + 触觉压力感知(70px 全方向,盲区也知道被贴着)
  • 记忆层:环形缓冲 30 条 + 一阶外推预测(T=0.35s,置信度衰减)+ 默契度(队友被遮挡用战术期望填补,不清空)
  • R4 效用重构:U = 收益 × 成功率估计 × 风格权重 × 风险系数(量纲统一 0~1,成功率查表初版)
  • R1 期望值空间价值:支援站位 V = P×Gain − (1−P)×Loss + 站两防守者之间的"创造空间"加分
  • R6 破局计时器 + 解围:被包围 3s 无路可走 → 生理性大脚解围 / 仓促射门
  • 定位球现实化:边线球(不再弹墙壁)+ 球门球双方站位复位
重大 bug 修复:系统性失衡
  • 现象:重构后红队 0 胜 6 负,比分 0:15
  • 定位:翻转攻击方向实验 → 失衡跟随"攻左"而非红蓝标签;dump 状态流发现:追身逼抢者在持球者背后,持球者的视野快照看不见他 → 对抗掷骰永不触发 → 谁抢到球谁就能无人阻拦带到球门
  • 修复:触觉/视野分离——压力与抢断用触觉(全方向,不看也知道),视野只负责认知层(站位/传球/过人)
修复后 6 场:红胜 3 / 蓝胜 1 / 平 2;抢断 39~48/场,拦截 10~17/场,传球 73~105/场。管线全量采样(位置/力/动作/球 0.5s)已接入。
